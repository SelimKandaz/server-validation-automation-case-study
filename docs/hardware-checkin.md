# Hardware Check-In Design

The check-in screen should show clean technician-readable categories:

- System model and serial/service tag
- BIOS/iDRAC/Lifecycle Controller versions
- CPU count and model
- Memory total, DIMM count and speed
- RAID/PERC/BOSS/NVMe/storage summary
- Network card product summary
- Power supply status
- Fan status and redundancy

The goal is to avoid noisy raw PCI output and show actual server identity.
